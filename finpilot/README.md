# 💰 FinPilot

> Seu dinheiro. Seu controle.

O **FinPilot** é um assistente financeiro desenvolvido em Python para
controle de receitas, despesas, metas e análise financeira.

O projeto nasceu como uma aplicação de terminal e foi desenvolvido
pensando em uma evolução gradual para um sistema completo de análise,
automação e inteligência artificial.

---

## 🚀 Funcionalidades

### 💰 Controle financeiro

- Cadastro de receitas
- Cadastro de despesas
- Categorias
- Cálculo automático do saldo
- Contagem de lançamentos
- Identificação da maior receita
- Identificação da maior despesa
- Percentual da renda comprometida

### 🎯 Metas financeiras

- Criação de metas
- Definição de valor objetivo
- Controle do valor acumulado
- Cálculo do progresso
- Adição de novos valores às metas

### 📋 Histórico

- Visualização de receitas
- Visualização de despesas
- Total de lançamentos
- Resumo financeiro

### 🤖 Análise financeira

O FinPilot possui uma camada inicial de análise baseada em regras
para interpretar a relação entre receitas, despesas e saldo.

Essa funcionalidade será evoluída posteriormente para utilizar
inteligência artificial.
